Upload a .tsv or .csv file in the format produced by a set's Export action. All tossups, bonuses, comments (including threaded replies), category tags and the category distribution come across, and the questions are added to the search index. Unknown commenters become inactive placeholder accounts so attribution is preserved.

Name a new set, or choose an existing set to add the questions to — which is how an archive too big for one upload arrives in several, without leaving a set behind per file. Adding to a set changes nothing that is already in it: categories are matched to the ones it has and only genuinely new ones are created, and its quotas, packets and name are left alone.
