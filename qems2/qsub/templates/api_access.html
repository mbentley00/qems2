Adding the Discord bot to your playtest server

Cliff reads the T | / B | question threads on a Discord server (set up with the Botero bot) and posts feedback, buzz points and bonus results to this set.

  1. Invite the bot to the server. Click here. You need Manage Server permissions on the Discord server to do this. Discord asks which server to add Cliff to: pick your playtest server under Add to server and press Continue, then accept the permissions on the next screen.
  2. Make sure it can see the playtest channels. If they're restricted to a role, right-click Cliff in the member list, open Roles, and tick that role (here, Bot). Or add the bot to those channels with View Channel and Read Message History.
  3. Copy your server's ID. Open User Settings (the gear by your name), search for “developer”, and switch on Developer Mode. Then right-click the server's icon in the server list and choose Copy Server Info → Copy Server ID.
  4. Link the server to this set. Generate the key above, then DM Cliff "add". It asks for the server ID, then for this set's key. Then DM it test to check the connection.
Using the bot
Syncing manually

@mention Cliff in any channel of a linked server to sync that server now. A sync can take a few minutes. Everything else is a direct message to the bot:

  • add — link a server to a QEMS set (walks you through the server ID and this page's key)
  • list — the servers currently linked and their autosync mode
  • test — check the connection. test answer posts a sample comment to that question.
  • autosync live / autosync nightly / autosync off — see below
  • remove server id — unlink a server
  • help — everything it understands

@Cliff debug shows which threads the bot can see and what it found, without posting anything.

How automatic syncing works

autosync live syncs once the server has been quiet for about 10 minutes. autosync nightly syncs once a day. autosync alone shows each server's mode.

If comments seem to be missing after a sync
  • Thread names. Only threads named like T | ... / B | ... (or ending | T1, | B2) are read as questions.
  • Unmatched questions. Comments attach to a question by its answer line. If the question isn't in this set or its answer has changed, the item is retried on a later sync. The sync report in Discord lists some unmatched answers.
  • Already synced. A thread with no new messages since the last sync is skipped.
  • Very short messages. Trivially short remarks ("lol", "+1") are filtered out of the feedback summary.
  • Permissions. Channels the bot can't see are skipped (see step 2). @Cliff debug shows which ones it can read.
  • Bot attribution. Synced comments appear under the bot's name. The summary text credits the playtesters.
