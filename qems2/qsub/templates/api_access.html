Adding the Discord bot to your playtest server

Cliff, the playtest bot, reads the T | / B | question threads on a Discord server (set up with the separate Botero bot) and posts the feedback, buzz points and bonus results to this set. Linking a server takes three steps.

  1. Invite the bot to the server. Click here. You need Manage Server permissions on the Discord server to do this. Discord asks which server to add Cliff to: pick your playtest server under Add to server and press Continue, then accept the permissions on the next screen.
  2. Make sure it can see the playtest channels. A server-level permission is overridden by private channels or categories. If your playtest channels are restricted to a role, give the bot that role: right-click Cliff in the member list, open Roles, and tick the role your playtest channels are open to (here, Bot). Or add the bot directly to those channels with View Channel and Read Message History.
  3. Find your server's ID. The bot asks for it when you link the server. Discord only shows IDs with Developer Mode on: open User Settings (the gear by your name), search for “developer”, and switch on Developer Mode. Then right-click the server's icon in the server list and choose Copy Server Info → Copy Server ID. The ID is a long number, now on your clipboard.
  4. Link the server to this set. Generate the key above, then DM the bot the message "add". It asks for the server ID you just copied and then for this key, and checks the key against QEMS before saving. test confirms the connection; autosync live makes it sync on its own a few minutes after playtesting goes quiet, or @mention it in any channel to sync right away. help lists everything it understands.
