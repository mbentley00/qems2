How often each style-check suggestion has been taken or thrown out, across every set. A suggestion rejected again and again is usually the suggestion's fault — a pronunciation guide for a name nobody mispronounces, an answer-line alternate that doesn't belong — and pulling it beats having every editor dismiss it separately.

Applying a fix counts as taken; dismissing it, for one question or for a whole set, counts as rejected. Restoring a dismissal takes the rejection back. Which set a verdict came from is deliberately not recorded.
